# PushState Guardian — Master Roadmap
## From v1 → v10

This document is the long-term architecture map for the project. It tracks the evolution from a basic pushState detector into a calm, privacy-first, explainable behavioral defense platform.

---

# v1 — PushState Interceptor
## Goal
Detect basic navigation abuse.

## Core capabilities
- pushState interception
- history manipulation monitoring
- back-button trap detection
- redirect burst warnings
- lightweight overlays

## Identity
A simple anti-navigation-abuse extension.
