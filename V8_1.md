# PushState Guardian - v8.1
## Codename: Invisible Cognition

## Goal
Let cognitive systems operate quietly while keeping explanations available on demand.

## Added systems
- invisible cognition layer
- explanation-on-demand model
- silent behavioral clustering
- background trajectory evaluation
- non-interruptive confidence updates
- cognition visibility controls
- quiet forecast summaries
- hidden-state audit trail
- cognitive privacy boundary
- user-readable reveal mode

## Runtime behavior
- Low-risk sessions show only a quiet forecast.
- The popup can reveal cluster, trajectory, forecast, explanation, and privacy boundary.
- Overlay stays compact unless risk is high or cognition is explicitly revealed.
- High-risk behavior overrides quiet mode.
- All cognition data remains local to the session and exportable for audit.

## Theme
The system can think deeply without constantly announcing that it is thinking.
