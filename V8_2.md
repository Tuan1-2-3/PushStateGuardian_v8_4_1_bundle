# PushState Guardian - v8.2
## Codename: Emotional Ergonomics

## Goal
Make warnings, friction, and recovery emotionally compatible with normal browsing.

## Added systems
- emotional tone engine
- stress-aware alert language
- warning intensity ladder
- reassurance without minimization
- recovery-first interaction flows
- fatigue-sensitive prompt timing
- user confidence preservation
- panic-avoidance copy rules
- humane escalation templates
- emotional safety review layer

## Runtime behavior
- Low-risk sessions use calm background language.
- Medium-risk sessions use quiet review language instead of alarm language.
- High-risk sessions are firm and visible but preserve user control.
- Recovery guidance is shown before deep forensic detail.
- Supportive copy can be disabled locally.
- Exported reports include tone, warning intensity, fatigue score, recovery action, and copy safety status.

## Theme
Security should reduce stress, not become another source of it.
