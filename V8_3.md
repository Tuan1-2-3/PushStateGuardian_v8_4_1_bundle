# PushState Guardian - v8.3
## Codename: Adaptive Calmness

## Goal
Adapt alerting and visibility to user context, behavior, and trust history.

## Added systems
- adaptive calmness engine
- attention budget model
- session quiet-hours logic
- trust-continuity scoring
- repeated-site calm profile
- alert cooldown memory
- mitigation softness selector
- local user preference learning
- interruptibility estimation
- calmness explainability layer

## Runtime behavior
- Low-risk repeated sites become quieter through local-only calm profiles.
- Medium-risk events are compacted during cooldown, quiet hours, or high trust continuity.
- High-risk behavior bypasses adaptive suppression and remains visible.
- Popup explains why a session is quiet, compact, or visible.
- Overlay uses a fixed top-right compact pill and no longer takes page layout space.

## Theme
The system should learn when to step back as carefully as it learns when to step in.
