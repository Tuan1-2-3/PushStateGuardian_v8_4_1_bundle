# PushState Guardian - v8.4
## Codename: Cognitive Minimalism

## Goal
Reduce visible complexity while preserving defensive depth, local preferences, and auditability.

## Added systems
- minimal surface mode
- compressed risk language
- simplified reason grouping
- progressive detail disclosure
- compact timeline summaries
- visual noise reduction
- low-cognitive-load popup design
- overlay simplification governor
- expert detail toggle continuity
- minimalism regression checks
- system/light/dark theme preference
- manual overlay visibility preference

## Runtime behavior
- The overlay no longer auto-appears during normal browsing by default.
- High-risk navigation pressure still expands the overlay so urgent risk is not hidden.
- Popup copy is user-facing by default; technical details stay behind Expert details.
- Theme preference is stored locally and supports System, Light, and Dark.
- Exported audit data still includes full signals, preferences, cognition, emotional ergonomics, adaptive calmness, and minimalism state.

## v8.4.1 stability patch
- Hidden overlay uses visibility/opacity instead of `display:none`.
- Overlay initializes from local preferences and listens for preference changes.
- Overlay can request a fresh content report if it starts before the first runtime update.
- Popup theme changes are applied atomically and batched with `requestAnimationFrame`.
- Popup includes a manual Show overlay action.

## Theme
Advanced defense should not require the user to understand every internal subsystem.

## Done definition
v8.4 is complete when:
- calm browsing is the default surface
- overlay visibility is locally reversible
- explanations remain available on demand
- theme mode works across popup and overlay
- high-risk behavior bypasses quiet display rules
- audit/export remains complete
